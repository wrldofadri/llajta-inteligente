# 🗺️ Mapa Inteligente de Incidencias Urbanas para Cochabamba

Sistema web para registrar, visualizar y gestionar reportes ciudadanos sobre problemas de infraestructura, servicios públicos y contaminación.

* **Backend:** Node.js, Express.js
* **Base de Datos:** MySQL
